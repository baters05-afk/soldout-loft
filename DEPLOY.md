# Размещение сайта на российском хостинге

Сайт статический: HTML, CSS, картинки. Единственная серверная часть —
приём заявок `api/lead.php`, ему нужен PHP 7.4+ с расширением cURL.
Это есть на любом обычном тарифе.

## 1. Загрузить файлы

В корень сайта (обычно `public_html` или `www`) кладём:

    index.html
    privacy.html
    agreement.html
    favicon.svg  icon-180.png  icon-512.png
    robots.txt  sitemap.xml  site.webmanifest
    assets/          — стили, скрипты, фотографии
    api/lead.php     — обработчик заявок

Файл `api/lead.js` нужен только для Vercel, на PHP-хостинге его не загружаем.

## 2. Настроить Telegram

1. В Telegram написать @BotFather → `/newbot` → получить токен.
2. Написать @userinfobot → получить свой числовой id.
3. Нажать «Старт» своему боту, иначе он не сможет вам писать.
4. На сервере скопировать `api/config.sample.php` в `api/config.php`
   и вписать туда токен и id.

Чтобы заявки приходили всей команде: создать группу, добавить в неё бота
и указать id группы (начинается с `-100`).

**Важно:** `config.php` держим только на сервере. В репозиторий он не
попадает — иначе токен окажется в открытом доступе и бота смогут увести.

## 3. Проверить

Открыть сайт, заполнить форму. Заявка должна прийти в Telegram.
Если пришла ошибка — смотреть лог PHP (в панели хостинга раздел «Логи»),
обработчик пишет туда причину.

## 4. Домен и HTTPS

Привязать `soloft.ru` в панели хостинга и включить бесплатный
сертификат Let's Encrypt — он есть у всех перечисленных провайдеров.

После смены домена поправить адреса в `index.html`:
`canonical`, `og:url`, `og:image`, а также ссылку в `robots.txt` и `sitemap.xml`.

## Если хостинг без PHP

Обработчик можно перенести в Yandex Cloud Functions (файл `api/lead.js`,
среда Node.js, токен в переменных окружения). Тогда в `index.html`
поменять `LEAD_URL` на адрес функции.
