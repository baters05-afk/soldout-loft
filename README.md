# SOLDOUT — лофт для мероприятий

Сайт площадки: ул. Малая Семёновская, д. 5, стр. 10, Москва.

## Состав

- `index.html` — главная
- `privacy.html` — политика обработки персональных данных
- `agreement.html` — согласие на обработку персональных данных
- `assets/img/` — фотографии площадки
- `assets/brand/` — логотип и фирменный паттерн

Статический сайт, сборка не требуется — файлы отдаются как есть.

## Что нужно donastroить

1. **Приём заявок.** Форма сейчас показывает заглушку — обработчик подключается
   в функции `sendForm` в конце `index.html`.
2. **Календарь занятости.** В настройках Google Календаря включить
   «Показывать только информацию о занятости (без подробностей)»,
   иначе на сайте видны имена клиентов и суммы.
3. **Аналитика.** Метрика подключается в функции `ckApply` — она вызывается
   только после согласия на cookie.
