# SOLDOUT — лофт для мероприятий

Сайт площадки: ул. Малая Семёновская, д. 5, стр. 10, Москва.

## Состав

- `index.html` — главная
- `privacy.html` — политика обработки персональных данных
- `agreement.html` — согласие на обработку персональных данных
- `api/lead.php` — приём заявок на Timeweb
- `assets/opt/` — оптимизированные фотографии площадки
- `assets/brand/` — логотип и фирменный паттерн

Сайт не требует сборки. Публикация на Timeweb выполняется автоматически при изменениях
в ветке `main`. Секреты SMTP и FTP не хранятся в репозитории.
